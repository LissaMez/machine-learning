# Telegram-бот для распознавания эмоций в русском тексте

![Python](https://img.shields.io/badge/Python-3.x-blue.svg)
![Telegram Bot](https://img.shields.io/badge/Telegram-Bot-blue.svg)
![Machine Learning](https://img.shields.io/badge/Machine%20Learning-Emotion%20Classification-purple.svg)

Проект представляет собой Telegram-бота, разработанного как прикладная часть курсовой работы по теме сравнения методов машинного обучения для распознавания эмоций в тексте.

В ходе курсовой работы были исследованы классические и нейросетевые методы классификации текста. На основе полученных моделей был реализован бот, который принимает сообщение пользователя на русском языке и возвращает результат распознавания эмоции сразу от трёх моделей:

1. Naive Bayes;
2. Logistic Regression;
3. TextCNN.

Бот распознаёт пять классов эмоций:

- `joy` — радость;
- `sadness` — грусть;
- `surprise` — удивление;
- `fear` — страх;
- `anger` — злость.

Проект показывает не только исследовательскую часть курсовой работы, но и пример практического применения обученных моделей в виде работающего Telegram-бота.

# Описание проекта

Основная задача проекта — определить эмоциональную окраску пользовательского текста. Пользователь отправляет сообщение в Telegram, после чего бот выполняет предобработку текста, передаёт его в обученные модели и возвращает предсказания с уровнем уверенности.

В проекте используются три подхода:

- **Naive Bayes** — классический вероятностный метод машинного обучения;
- **Logistic Regression** — линейная модель, часто применяемая для задач классификации текста;
- **TextCNN** — нейросетевая модель, использующая свёрточные слои для извлечения локальных текстовых признаков.

Такой формат позволяет сравнить результаты разных методов не только в ноутбуках и таблицах, но и в прикладном интерфейсе, удобном для демонстрации.

# Файлы обученных моделей

В папке `bot/saved_models/` после обучения должны находиться следующие файлы:

| Файл | Назначение |
|------|------------|
| `naive_bayes_model.pkl` | обученная модель Naive Bayes |
| `naive_bayes_vectorizer.pkl` | TF-IDF-векторизатор для Naive Bayes |
| `logreg_model.pkl` | обученная модель Logistic Regression |
| `logreg_vectorizer.pkl` | TF-IDF-векторизатор для Logistic Regression |
| `textcnn_model.keras` | обученная нейросетевая модель TextCNN |
| `textcnn_tokenizer.pkl` | токенизатор для TextCNN |
| `textcnn_label_encoder.pkl` | кодировщик меток классов для TextCNN |
| `textcnn_max_len.pkl` | сохранённая максимальная длина последовательности для TextCNN |

Эти файлы нужны не только для локального запуска, но и для работы бота на сервере. Если папки `bot/saved_models/` нет или в ней отсутствуют нужные файлы, необходимо сначала запустить обучение моделей.

# Установка и запуск локально

1. Клонировать репозиторий:

```bash
git clone https://github.com/USERNAME/emotion_bot_project.git
cd emotion_bot_project
```

2. Создать виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate
```

Для Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

3. Установить зависимости:

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

4. Создать файл `.env` в корне проекта:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_telegram_бота
```

Токен можно получить через Telegram-бота `@BotFather`.

# Обучение моделей

Перед первым запуском бота необходимо обучить модели и сохранить их в `bot/saved_models/`.

```bash
python bot/train_models.py
```

Скрипт обучает три модели:

- Naive Bayes;
- Logistic Regression;
- TextCNN.

После завершения обучения в папке `bot/saved_models/` появятся файлы моделей и вспомогательные объекты, необходимые для предсказания.

# Запуск Telegram-бота

После установки зависимостей, создания `.env` и обучения моделей бот запускается командой:

```bash
python bot/bot.py
```

После запуска в терминале должно появиться сообщение:

```text
Бот запущен.
```

Далее можно открыть Telegram, перейти к своему боту и отправить команду:

```text
/start
```

После этого бот будет принимать текстовые сообщения и возвращать предсказания трёх моделей.

# Тестирование

Для проверки полного пайплайна используется `pytest`.

```bash
pytest
```

Тест проверяет, что:

- необходимые файлы моделей существуют;
- функция предсказания возвращает словарь;
- ответ содержит результаты трёх моделей;
- предсказанная эмоция входит в допустимый набор классов;
- уверенность модели находится в диапазоне от 0 до 1;
- текстовый ответ корректно форматируется для пользователя.

Если модели ещё не обучены, smoke-тест будет пропущен с пояснением, что сначала нужно запустить обучение.

# Связь с курсовой работой

Данный Telegram-бот является прикладной частью курсовой работы. В исследовательской части были реализованы, обучены и сравнены разные методы машинного обучения для распознавания эмоций в тексте. После этого результаты были использованы в практическом приложении.

Бот демонстрирует, как модели, обученные в рамках эксперимента, могут применяться в реальном пользовательском сценарии. Пользователь не взаимодействует с кодом, датасетами и ноутбуками напрямую: он просто отправляет текстовое сообщение, а система возвращает классификацию эмоции.

Такой формат делает проект более завершённым, потому что он включает:

- подготовку и обработку текстовых данных;
- обучение нескольких моделей;
- сравнение классических и нейросетевых подходов;
- сохранение обученных моделей;
- реализацию модуля предсказания;
- создание Telegram-интерфейса;
- тестирование пайплайна;
- проверку качества кода;
- возможность развёртывания на удалённом сервере.

Таким образом, проект показывает полный путь от исследовательской задачи до работающего программного решения.
